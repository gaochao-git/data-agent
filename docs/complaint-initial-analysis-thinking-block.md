## 目前实现（初次回答，/api/complaint/text）


当前“初次回答”走 `TextPipeline`（上传 → OCR → 摘要）时，实际下发的 steps 结构如下：

- 思考步骤（node_id: <message_id>-thinking）：label 先是“正在制定分析思路”，结束时改为“思考完成”，detail 为规划内容
    代码：server/apps/complaint_app/services/text/text_pipeline.py（_stream_tool_planner, _ensure_step, _set_step_detail, _set_step_status）
- 工具调用父步骤（node_id: <message_id>-tool）：label “工具调用”，含 children
  代码：server/apps/complaint_app/services/text/text_pipeline.py（_ensure_tool_parent_node, _ensure_child_step）
- 工具调用 children（顺序/内容与 SSE 一致）
    - complaint_upload：label “原件上传”，detailLines 含上传提示
      代码：server/apps/complaint_app/services/text/text_pipeline.py（_emit_task0）
    - complaint_ocr：label “原文提取”，detailLines 含 OCR 进度
      代码：server/apps/complaint_app/services/text/text_pipeline.py（_run_task1_ocr）
    - complaint_summary：label “摘要生成”，detailLines 含摘要内容
      代码：server/apps/complaint_app/services/text/text_pipeline.py（_run_tool_summary_pipeline）

### 思考步骤（1 条）
```
{
  "id": "<message_id>-thinking",
  "label": "",
  "status": "done",
  "detail": "我将按以下步骤处理：首先仔细审阅这些举报材料，随后为您整理出一份核心摘要，以便快速掌握关键要点。"
}
```
说明：开始阶段 label 为“正在制定分析思路”，结束时更新为“思考完成”，detail 为规划文本。

### 工具调用父步骤（1 条，含子步骤）
```
{
  "id": "<message_id>-tool",
  "label": "工具调用",
  "status": "done",
  "children": [
    { "id": "complaint_upload", "label": "原件上传", "status": "done", "detailLines": [...] },
    { "id": "complaint_ocr", "label": "原文提取", "status": "done", "detailLines": [...] },
    { "id": "complaint_summary", "label": "摘要生成", "status": "done", "detailLines": [...] }
  ]
}
```
说明：
- `complaint_upload`：上传/接收文档提示。
- `complaint_ocr`：OCR 进度与完成提示。
- `complaint_summary`：摘要正文以 `detailLines` 形式回传。
