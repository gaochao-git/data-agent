# 智能体问答准确性评测

> 2026-10-25：本文件保留为执行记录；问答对维护入口见
> [`server/apps/chat_data_app/tests/eval-sets/电商问数评测集.md`](../../server/apps/chat_data_app/tests/eval-sets/电商问数评测集.md)。

版本：2026-10-25  
执行方式：其他智能体在智能问数页面逐条提问，按标准答案判定准确性。  
本文件即完整评测用例，包含问题、标准答案、评分规则和输出格式。

## 环境

```text
URL：http://localhost:8089/chatdata?parentComponentName=执法检查
模型：deepseek/deepseek-v4-flash
本体：火星电子商务有限公司
数据时点：2026-10-24T13:41:46Z
只读，不执行写操作
```

要求：

- 必须选择 `deepseek/deepseek-v4-flash`
- 每题新建会话或明确隔离上下文
- 单题最多等待 180 秒
- 按语义评分，不要求逐字一致
- 金额、订单号、状态、数量错误即 FAIL
- 编造不存在的数据即 FAIL
- 记录回答原文、截图、耗时

## 用例

### QA-001 杜佑名下订单列表

提问：

```text
杜佑名下有哪些订单？请给出订单号、金额和支付状态。
```

标准答案：

```text
2 笔订单
ORG1-ORD001906：1502.46，refunded
ORG1-ORD004041：537.51，delivered
```

必须包含：2 笔、两个订单号、两个金额、两个状态。  
不得出现：第三笔订单、金额或状态记反。

---

### QA-002 订单数量与最大单笔金额

提问：

```text
杜佑有多少笔订单？最大单笔金额是多少？
```

标准答案：

```text
2 笔；最大单笔 1502.46
```

---

### QA-003 金额合计与退款口径

提问：

```text
杜佑名下订单金额合计是多少？其中已退款金额多少，剔除退款后的有效金额多少？
```

标准答案：

```text
名义合计 2039.97
已退款 1502.46
有效金额 537.51
不能把 2039.97 直接当作实际消费额
```

评分：

- 三个金额正确并说明退款口径：PASS
- 金额正确但不解释退款：PARTIAL
- 金额错误或把名义金额当有效金额：FAIL

---

### QA-004 机构范围

提问：

```text
杜佑在支付宝有订单吗？他在哪些机构有数据？
```

标准答案：

```text
只在财付通 / ORG_CODE1 命中
支付宝及其他机构无匹配
```

不得声称支付宝有杜佑订单。

---

### QA-005 不存在客户不编造

提问：

```text
查一下客户「张三不存在」名下的订单。
```

标准答案：

```text
未找到该客户或没有匹配数据
```

不得编造订单或把杜佑订单当成张三的。

---

### QA-006 不存在第三笔订单

提问：

```text
杜佑的第三笔订单是什么？
```

标准答案：

```text
杜佑只有 2 笔订单，不存在第三笔
```

不得编造第三笔订单。

---

### QA-007 发货单与物流

提问：

```text
订单 ORG1-ORD001906 的发货单和物流单号是什么？
```

标准答案：

```text
发货单 ORG1-SHIP001821
物流单号 ORG1-TRK0000001821
```

不得与 ORG1-ORD004041 的发货单混淆。

---

### QA-008 已退款订单

提问：

```text
杜佑哪笔订单已退款？退款金额是多少？
```

标准答案：

```text
ORG1-ORD001906，已退款 1502.46
```

---

### QA-009 高金额订单

提问：

```text
杜佑名下订单中，金额大于 1000 的订单有哪些？
```

标准答案：

```text
只有 ORG1-ORD001906，1502.46，refunded
```

不得包含 ORG1-ORD004041。

---

### QA-010 明细与发货数量

提问：

```text
杜佑两笔订单分别有多少条订单明细和发货单？
```

标准答案：

```text
ORG1-ORD001906：3 条明细，1 个发货单
ORG1-ORD004041：2 条明细，1 个发货单
```

## 输出格式

每题输出：

```json
{
  "case_id": "QA-001",
  "status": "PASS",
  "agent_answer": "原文",
  "missing_facts": [],
  "wrong_facts": [],
  "hallucination": false,
  "duration_ms": 30000,
  "evidence": "会话截图或链接"
}
```

最终汇总：

```text
PASS / PARTIAL / FAIL / BLOCKED 数量
错误事实清单
是否存在编造
是否建议发布
```
