# Starts with

Returns True if the input string starts with the specified substring (case-sensitive). Treats special characters such as `.`, `/`, `@`, `-`, and `spaces` as part of the literal search string, as opposed to the "contains" transform which uses special characters as word boundaries.

## Input type

String

## Output type

Boolean
