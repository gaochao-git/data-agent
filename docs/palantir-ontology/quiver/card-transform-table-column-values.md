# Transform table column values

Takes a number, string, time, or boolean column from a transform table as input and returns an array of the column values.

## Input type

Transform table

## Output type

Number array, string array, time array, boolean array

## Usage information

| Functionality | Availability |
| --- | --- |
| [Standard Quiver card](/docs/foundry/quiver/core-concepts/#cards) | Supported |
| [Transform table transform](/docs/foundry/quiver/cards-transform-table/) | Unsupported |
