# Object selector

Provides a dropdown widget for selecting a single object from an input object set or object type. Useful for building interactive dashboards. To guide the user on how to select a specific object, configure a **Prompt** and **Help text**. To show a view of the selected object, turn on **Show object view** or add an **Object view** card from the **Next actions** menu.

When popping out a single object row from an object set card, an object selector is automatically added to the analysis.

## Input type

None, Object set

## Output type

Single object
