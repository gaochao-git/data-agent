# Palantir API Reference — Attachment basics

> 来源: https://www.palantir.com/docs/foundry/api/v2/ontologies-v2-resources/attachments/attachment-basics/
> 抓取: 2026-10-17（本地参考副本，版权属 Palantir）

---

An Attachment is a file that acts like a parameter of an object. Attachments are uploaded as temporary files 
and attached to objects via actions. Attachments are configured in the **Ontology Manager**. For more information, 
please checkout the [Upload attachments](/docs/foundry/action-types/upload-attachments/) user documentation.
