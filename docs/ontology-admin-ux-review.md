# 本体管理端 UX Review（2026-10-24，基于全轮浏览器实测）

覆盖面板：本体树导航、对象类型表单（含派生编辑器）、对象实例探索器、详情面板、图谱、Action 面板、一致性巡检、写性配置。证据来自当日全部浏览器测试轮次（§5.32/§5.33 及写回功能验证）。

## P0（直接影响使用，建议先修）

| # | 问题 | 证据 | 建议 |
| --- | --- | --- | --- |
| 1 | **树分组展开箭头视觉不可见**：所有子级都收在"对象类型 6"这类分组下，行首箭头肉眼难辨、ARIA 也不暴露，展开只能靠点箭头小区域 | 自动化与人工多次在树上迷路（今日 3+ 次）；单机分组行单击只选中不展开 | 箭头加大/加 hover 高亮；或分组行单击即展开（单击选中改为双击） |
| 2 | **搜索体验断裂**：① 不即时过滤，必须点"搜索"按钮；② 只匹配展示名不匹配 API 名（搜 `qa_test_ontology` 无结果、搜展示名才有）；③ 清空搜索后计数残留显示"对象类型 0"（DEF-6） | A03 实测；qa_test 本体创建后找不到 | 输入即过滤（300ms 防抖）；匹配同时命中 API 名与展示名；清空即恢复全树 |
| 3 | **超时错误文案误导**：列表加载超时提示"请检查映射和数据源权限"——实际是 Hive 慢，把用户引向完全错误的排查方向 | DEF-2/DEF-4 期间多次出现 | 文案区分超时与权限：超时提示"数据源查询较慢，请稍后重试或缩小范围" |

## P1（明显摩擦，排期修）

| # | 问题 | 建议 |
| --- | --- | --- |
| 4 | 新建本体/对象类型成功后树不自动出现新节点，需手动刷新 | 保存成功后局部刷新树并选中新节点 |
| 5 | 实例列表加载 5-10s 无进度预期（Hive 固有耗时），只有转圈 | 加载提示带耗时预期（"Hive 查询约 5-10 秒"）或骨架屏 |
| 6 | 实例列表面板只有标题+主键两列，派生值列看不到 | 列表支持列选择（含派生属性），或行展开显示全部属性 |
| 7 | 右键菜单是树的主要操作入口，可发现性弱（底部一行小字提示） | 树顶加显式"新建"按钮组；或选中节点后右侧面板顶部放操作按钮（编辑/状态/删除） |
| 8 | Action 执行入口在管理端不可见（定义/试运行有 UI，执行目前只有 API） | Action 详情面板加"执行"按钮（带参数表单与二次确认），审计列表同面板可查 |
| 9 | QA 遗留：写性变更无二次确认（read_only→action_writable 是放宽可直接改；→action_created 有后端互斥校验兜底，但 UI 无提示） | 变更到 action_created 时前端先弹确认说明形态变化 |

## P2（打磨项）

- 10. 对象类型表单一屏平铺很长（基本信息/Dataset/映射/属性），新建流程无分步；可接受但新手指引弱
- 11. 巡检"检查"按钮与"图谱"并列在树行上，语义不直观；可改名"体检"或收进详情面板
- 12. 树上无全局写性/状态视图（想看"哪些对象可写"要逐个点开）；详情页签可加过滤
- 13. 派生属性候选/过滤候选已排除派生（DEF-3 修复后需回归确认）
- 14. 图谱节点布局较基础（5 节点级联），大本体时可用性未知

## 已验证的良好体验（保持）

- 派生属性编辑：独立对话框 + definition summary 一行展示完整定义（关系·算子·目标·时间窗·过滤）——信息密度恰到好处
- 详情页签计数（属性 5/关系 1/动作 1）+ 写性标签 + certified 冻结提示（"如需结构性变更请先降级"）治理语义清晰
- 关系 verbalize 双向口语化；巡检 findings 分级可读（警告/提示/官方引用）
- 错误处理：非法输入行内校验文案具体（"属性名仅允许字母数字下划线"），不白屏
