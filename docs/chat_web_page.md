# 聊天页面背景及结构说明
可以让用户与AI智能体对话的一个页面。

### 现状：
目前已经在 ./web/src/pages/GeneralAssistant/components/AgentContainer.tsx 中实现了动态加载不同Agent的聊天对话。比如：
1、法律检索：./web/src/pages/AISpecialistHome/EmbeddedLayout.tsx
2、举报件办理：./web/src/pages/ComplaintAnalysisNew/EmbeddedLayout.tsx

每个agent都有自己的使用情况，但是整体的思路都是相似的，所以，希望将这2个模块合并成一个新的，前端通用的就通用的显示，不通用的部分，就通过agent的元数据来控制，后端也同样如此。
前端Agent元数据位于 `web/src/pages/GeneralAssistant/agentRegistry.ts`。


### 目标是：
1、上面2个模块的前端页面合并成一个新的，新的前端设计已经完成，见./ai标记图/index.html，后端也希望是希望保持相同的接口与sse数据结构。
2、通过AgentID来渲染不同的智能体应该显示的组件内容。 建议新增并规范以下 UI 配置字段：
- `opening_message`：初始化状态下聊天窗口的开场文案（前端配置）。
- `input_actions`：输入框下方按钮区配置（如 DeepSeek-R1/深度思考/自定义按钮）。
3、布局结构还是分为左右两部分，左侧为聊天窗口，右侧为工作台。分为初始化状态、对话状态。
    初始化状态：
        1、工作台不显示。
    对话状态：
        1、工作台显示对应Agent的不同TAB信息。


### 初始化态与会话态规则（建议新增）
- 初始化态：左侧仅显示开场文案，右侧工作台不显示。
- 会话态：左侧显示消息流；右侧显示工作台。
- TAB 激活规则：前端固定 TAB 列表；后端可在 SSE 事件中指明“当前激活 TAB”，前端仅切换激活状态，不改变 TAB 列表。


#### part I 聊天窗口（左）
聊天窗口也和之前的结构保持一致，分为上下结构，上方为对话记录，下方为输入框。
聊天记录：
    初始化状态：
        - 对话记录：不同的Agent渲染不同的一句内容，表示当前Agent的功能。居左显示，例如：
            -- title：举报件AI {时间戳}
            -- content: 我是举报件AI辅助助手，请先上传举报件，我来帮助您快速了解举报内容。
            或
            -- title：法律索引AI  {时间戳}
            -- content: 我是法律索引AI辅助助手，我来帮助您快速了解法律内容。
        - 下方输入框：包括：对话框、对话框内下方一行
            -- 左侧显示“Deepseek R1”、“深度思考”、以及 法律检索 或 举报件处理 2部分对应的自定义的按钮
            -- 右侧显示发送按钮（动作：调用后端对话的API接口，协议见./chat_protocol.md）、附件按钮。

    会话状态（一个会话界面使用conversation_id表示一个会话）：
        - 对话记录：不同的Agent渲染不同的历史记录内容（第一步是举报件和法律索引查询各自的历史记录）：
            1、左侧显示AI回复内容、右侧显示用户输入内容；
            2、左侧AI回复内容支持：思考、答复；思考内包括思考的内容，工具调用内容；

        - 下方输入框：包括：对话框、对话框内下方一行
            发送按钮改为回复中的按钮状态，支持用户取消回复（动作：调用后端取消回复的API接口）


#### part II 工作台（右）
当AI回复的过程中，会产生出一些artifact，工作台则是用于显示当前agent（举报件办理/法律索引）。
目前两个agent显示的artifact内容如下：
- 法律索引：点击对话中的引用，在右侧显示对应的法律原文（通过点击查询详情的接口）
- 举报件办理：对话中的时候，自动显示右侧工作台，显示出当前举报件的原件（上传的pdf/图片）和AI提取出来的原文内容

### 工作台内容来源与激活（建议新增）
- 右侧工作台的内容由 SSE 事件与后端查询接口共同驱动。
- SSE 中可以指定“当前激活 TAB”（用于切换视图），但不允许新增/删除 TAB。
- 当 SSE 仅携带内容时，默认更新当前激活 TAB 的内容；当内容来自二次查询接口时，应明确该接口与 TAB 的对应关系。
