## 样式系统迁移说明

### Tailwind CSS 使用规范
- 颜色: `bg-gray-50`, `text-indigo-600`, `border-gray-200`
- 暗色模式: `dark:bg-gray-900`, `dark:text-gray-100`
- 圆角: `rounded-2xl`, `rounded-lg`
- 阴影: `shadow-sm`, `shadow-md`
- 过渡: `transition-all`, `hover:bg-gray-100`

### 动画实现
- 使用 Vue `<Transition>` 和 `<TransitionGroup>`
- CSS @keyframes 定义动画
- 类名: `animate-fade-in`, `animate-slide-up`
