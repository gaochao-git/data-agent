# MCP 工具每工具审批配置（ask / allow / force_ask / deny 四档）

## 已拍板决策
- `plugin.json` 的 `mcp_servers[]` 新增可选字段 `tool_approvals: {"<原始工具名>": "ask"|"allow"|"force_ask"|"deny"}`，缺省即 `ask`
- deny = 装配期剔除（不挂载、不可检索、不占 token）；force_ask = 覆盖运行档位的强制审批（本次新增）
- 存量行为零变化：不配置该字段 = 现状

## 四档语义矩阵
| 配置 | ask 运行档(交互) | auto 运行档(交互) | auto+无人值守 |
|---|---|---|---|
| ask(缺省) | 执行前审批(现状) | 直接执行 | 直接执行 |
| allow | 免审批放行 | 直接执行 | 直接执行 |
| force_ask | 执行前审批 | **仍强制审批**(覆盖运行开关) | **不挂载**(fail-closed) |
| deny | 不挂载/不可检索 | 同左 | 同左 |

三条硬语义：force_ask 只覆盖自己（auto 下其余工具仍直行）；无人值守照 ask_user_question 先例（data_agent.py:241-255 按 requires_user_interaction 跳过装配）不挂载、不挂死；会话/本轮 grants 显式授权照常豁免 force_ask（管理端已有 grants revoke/reset 治理口，若需"绝对每问必答"后续再收紧）。内置 approval_required 工具在 auto 下行为本次不动。
