# 全局分析评测集

eval_set_id: 全局分析评测集
eval_set_name: 全局分析评测集
测试目标：验证全局指标分析能力：按时间、机构、支付状态做聚合与对比，关注指标值与口径。

运行环境见 [README.md](./README.md)。

## 用例 1

测试目标：验证按时间和机构过滤后的订单总量统计是否正确。

问题：2025 年支付宝有多少订单？

答案：2025 年支付宝共 1422 笔订单。

## 用例 2

测试目标：验证按时间 + 机构 + 支付状态分组计数是否正确。

问题：2025 年支付宝的订单按支付状态分布分别是多少？

答案：已取消（cancelled）59 笔、已送达（delivered）1218 笔、已支付（paid）35 笔、待支付（pending）8 笔、已退款（refunded）64 笔、已发货（shipped）38 笔。

## 用例 3

测试目标：验证跨机构订单量对比（全局汇总）是否正确。

问题：2025 年各机构的订单量分别是多少？按从高到低排。

答案：财付通 1868 笔、支付宝 1422 笔、平安付 1022 笔、拉卡拉 308 笔、银商务 0 笔、货拉拉 0 笔。

## 用例 4

测试目标：验证按时间 + 机构聚合金额，并区分名义金额、已退款金额和有效金额。

问题：2025 年财付通订单金额合计是多少？其中已退款金额多少？剔除退款和取消后的金额多少？

答案：名义合计 4,294,938.51；已退款 122,975.68；剔除退款和取消后的有效金额 3,896,739.48。
