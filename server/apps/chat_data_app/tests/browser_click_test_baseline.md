# ChatData 浏览器点击测试基础版

> 本文档由 v1（发布版本必测功能）与 v2（浏览器点击测试待测项）合并而成，作为每次发布 / 回归时**必须通过浏览器页面点击验证**的基础回归清单。
>
> - 仅收录需通过页面点击验证的项；纯 API、单元测试、mock、数据库或日志验证不在此列。
> - 发布通过标准：下方主流程全部能通过页面点击完成。

## 前置数据

- 账号：管理员账号、普通账号、无可用机构权限账号。
- 数据：至少 1 个可用数据源、1 个多执行对象数据源、1 个可用指标集、1 个已有会话、1 个已有看板、1 个已发布技能；另准备 1 个未发布草稿用于验证运行期不可加载。
- 页面入口：依据配置数据源的「映射」与智能问数页面进行绑定。
- 权限回收场景：环境侧先回收部分机构权限，再刷新页面验证。

## 1. 页面入口与权限

- 管理员进入对应页面，可切换数据智能体、可视化查询、SQL 查询、数据看板、指标集配置，页面无白屏、无无限 loading。
- 普通账号进入页面，后台管理类入口不可见或不可操作，个人可用数据正常展示。
- 无可用数据源或无机构权限账号进入页面，应展示空状态或无权限提示，不能误触发查询。
- 切换数据源、指标集、执行对象和功能模式后，页面状态不串台。

## 2. 数据源管理

- 管理员是按照角色+白名单用户进行管理，只有配置了白名单的用户才具有管理权限
- 管理权限是通过前后端进行权限管理，非管理员前端看不到按钮、后端调用不了接口
- 管理员打开数据源管理，未修改配置时「保存配置」不可点击。
- 只修改基础配置并保存，不应触发表结构刷新。
- 点击「拉取表信息」只用于选择表；只有点击「同步元数据」才更新表结构缓存。
- 管理员打开数据源管理，查看、编辑、保存数据源配置流程正常。
- 编辑数据源组后取消或关闭，再次打开应恢复服务端已保存状态。
- 删除数据源时，取消不改变列表；确认删除有 loading，成功后主页面不残留已删除数据源。

## 3. 指标集配置

- 管理员新建、编辑、删除公共指标集；保存后智能体、可视化查询、SQL 查询可选择，删除后不可选择。
- 普通账号新建或编辑私有指标集；其他普通账号不可见或不可编辑。
- 新建公共指标集，选择表、字段、维度、指标并保存，智能问数和可视化查询能选择到。
- 自动预填填写或不填写业务补充后，候选字段正确填充；字段表达式弹窗和表关联弹窗可编辑保存 / 取消，用户二次编辑不被异步结果覆盖。
- 自动预填只生成页面候选，不直接保存指标集；修改维度、指标、聚合方式或关系后，点击保存才写入配置。
- 编辑和删除指标集有确认或提示，保存后页面列表、下拉选择和历史引用表现一致。
- 历史学习入口有明确成功或失败提示。

## 4. 数据智能体

- 选择数据源、指标集、单个执行对象，输入明细查询，能生成 SQL、执行查询并展示结果表格。
- 选择多个执行对象做聚合 / 明细查询，结果按成员展示，用户能看清 `member_name` 与每个成员状态。
- 页面不重复展示外层结果和成员结果，不同时展示互相矛盾的成功状态。
- 右侧控制台展示 JSON / 工具详情，不重复展示主结果表格。
- 工具卡片可展开详情，保留真实工具名，参数和结果可折叠且格式化可读；大结果不撑破页面；不重复展示无用工具名或重复参数。
- 查询结果可保存到看板，保存后看板面板包含标题、SQL、执行对象和结果展示信息，能正确带上 SQL、结果、执行对象信息。
- 新建会话、切换历史会话后，消息、工具调用和查询结果可恢复。
- 切换多模型可以正常显示、切换思考模式可以正常显示。
- 通过语言描述或 `/` 可以唤起技能；未发布的用户技能只能在技能管理中编辑，不能被运行期 Agent 加载。
- 回收部分机构权限后刷新页面，新查询不可选择已回收执行对象，历史会话不能绕过当前权限再次执行。
- 长会话中用户提问达到 6 轮，或消息内容超过约 2 个视口高度时，桌面端右侧显示用户轮次定位圆点；点击任一圆点定位到对应用户提问及其回答链路，滚动时当前轮高亮；移动端不显示该导航，右侧工具详情打开时不遮挡详情内容。

## 5. 会话文件与产物

- 在数据智能体输入栏上传支持的文本或 Office 文件，文件出现在当前会话的 `uploads` 区域；上传文件保持只读，不能被 Agent 直接覆盖。
- 对上传的纯文本文件，Agent 可以直接读取；对二进制文档，先调用文档解析能力生成 workspace 中的可读文件，再继续分析。
- Agent 生成 Markdown 文件后，右侧控制台可以在「预览」和「源码」之间切换；切换不改变文件内容，长内容可滚动查看。
- 右侧文件树可以展开、收起、刷新和选择文件；workspace / outputs 文件的内容预览、下载和历史会话恢复状态正确。
- 生成图表、看板规格或技能产物时，只有写入 `outputs` 并成功展示预览后，页面才显示对应交付状态；失败时显示可读错误，不伪装成已生成。

## 6. 上下文与系统提示词

- 默认配置下，上下文用量详情不展示 system prompt 原文。
- 模型 API 返回缓存 token 时，上下文详情展示当前/累计缓存命中及命中率；未返回该字段的模型不展示缓存区块且对话正常完成。
- 模型已返回过缓存 token 后，流式调用工具或下一次模型调用期间，缓存区块保持四个固定卡位；尚未返回当前调用的完整 usage 时展示「统计中」，结束后显示最终命中率，不在输出过程中反复增删卡片。
- 同一会话发送下一轮时，上下文圆环和详情先沿用上一轮有效值，收到本轮首个 usage 后更新；切换历史会话或新建会话时才清空，不能在流开始阶段闪为空白。
- 连续多轮问数触发压缩后，当前正在执行的一轮不丢失，后续问题仍能理解已确认的数据源、指标集和执行对象；切换到该历史会话后，用户消息、思考块、工具调用、工具结果和最终回答与实时展示顺序一致，不能出现思考或工具错位、重复或缺失。
- 上下文超过限制可以正常压缩任务不中断。
- 压缩后上下文用量展示应反映压缩后状态，不一直显示完整历史总量。

## 7. SQL 查询

- 选择数据源和单个 / 多个执行对象，输入合法 SELECT SQL，点击执行后异步任务完成并展示结果（使用共享结果展示）。
- 数据智能体查询结果显示实际查询模式：常规语义查询显示 `DSL 模式`；只有 DSL 无法表达时直接执行只读 SQL，显示 `SQL 模式`。历史结果中的旧模式值仍能正确显示。
- 选择多个执行对象执行同一 SQL，每个成员结果独立展示，行数、耗时、错误信息正确。
- 选择多个执行对象执行多个 SQL，每个成员结果独立展示，行数、耗时、错误信息正确。
- 输入高危 SQL 或非法 SQL 时，页面展示清晰错误，不执行危险操作。
- 跨库越权查询能够正常拦截。
- 输入单条 SQL 语法错误（例如 `LIMIT1 100`）后，错误在结果区域按执行对象展示，不弹出全局异常；默认展示首行摘要，点击「展开错误详情」可查看完整原始错误，收起后页面不溢出。
- SQL 编辑器运行、格式化等快捷键只在当前页面生效；运行 SQL、格式化 SQL 快捷键能够正常使用；AI 辅助生成 SQL 能流式回填编辑器，用户编辑不被后续流式片段覆盖。
- 发起耗时 SQL 后点击停止，任务状态进入已停止、失败或部分成功，历史记录状态一致；包括管理页面全局暂停、个人用户所有 SQL 暂停、单批次任务通过暂停运行按钮暂停、SQL 历史暂停单 SQL。
- SQL 历史、收藏、重新执行、删除收藏流程可通过页面完成。

## 8. 可视化查询

- 选择维度、指标、过滤、排序和 limit 后点击执行，生成 SQL 与页面配置一致并展示结果。
- 点击 SQL 预览或开始查询后立即修改筛选条件，本次预览 / 执行仍使用点击时的配置；下一次操作才使用修改后的配置。
- 修改查询条件后再次执行，应刷新为新结果，不复用旧结果。
- 普通账号只能预览本人私有指标集或公共指标集；其他用户的私有指标集不可见、不可预览、不可执行。
- 高级过滤树支持多层 AND / OR，展开、收起、删除、编辑不丢节点，删除后不残留旧过滤。
- 多执行对象可视化查询结果与 SQL 查询展示口径一致。
- 点击维度、指标区的设置按钮，分别打开管理弹窗；勾选删除、上下调整顺序、修改展示名称或聚合函数后保存，主配置区立即按保存结果更新；点击取消不修改主配置。
- 查询结果出现后，点击图表展示和结果分析 Tab、收起按钮及折叠后的竖向入口，面板可在对应 Tab 恢复，查询结果、图表类型、表格格式和分页设置不丢失。
- 图表展示中切换表格、柱状图、条形图、折线图、面积图、饼图、指标卡、地图、漏斗图和关系图，结果预览随选择更新；切换基本格式和分页器开关、页大小后，结果展示与分页行为一致。
- 结果分析依次点击排序、Top N、合计、百分比、对比、同环比并执行，结果仅在当前展示数据上变化且不修改 SQL；取消分析后恢复原始查询结果。
- 已有结果分析时继续执行另一种分析，使用当前展示结果作为输入；重新执行可视化查询或重置配置后，分析结果和分析条件清空，不能残留到新查询。
- 时间维度按周时，同环比入口不可执行并展示「暂不支持按周」提示；按年、季度、月、日时可执行，同环比结果字段、图表语义和原始结果切换正确。
- 可视化查询结果保存到看板后，面板图表类型、SQL、执行对象和结果正常。

## 9. 数据看板

- 面板增删改查功能正常。
- 从数据智能体、SQL 查询、可视化查询分别保存结果到看板，面板标题、图表类型、SQL、执行对象正确；多执行对象结果保存后能区分成员数据。
- 打开已有看板，面板列表、布局、图表和表格能正常加载。
- 单面板刷新有 loading，完成后图表和表格更新。
- 批量刷新多个面板时，成功和失败面板互不影响，失败提示可读。
- 编辑看板名称、面板名称、布局、图表类型并保存，刷新浏览器后配置不丢失。
- 回收部分机构权限后，已无权限执行对象不可新选择；绑定已回收执行对象的面板刷新失败时提示清晰。
- 跨入口保存到看板的字段横向一致：对同一批执行对象、同一段 SQL，分别从智能问数、SQL 查询、可视化查询三种入口保存到同一个看板，各面板所记录的 `SQL`、`执行对象（member_name / member_datasource_id）`、`结果字段（columns / data）`、`图表类型 / 分页设置` 口径完全一致，不出现某入口多 / 少字段、执行对象名称拼接格式不同或状态矛盾等漂移。

## 10. 会话历史

- **增**：点击侧边栏「新建会话」（数据智能体 `AnalysisConversation.vue`），清空当前状态；发送第一条消息后服务端才真正创建会话。
- **查**：在会话侧边栏（或 `ConversationSidebar.vue`）切换历史会话，会话标题、消息、工具调用、查询结果、生成文件、文件树和预览状态可恢复。
- **改**：修改会话标题后保存，列表与头部展示同步更新（后端 `PUT /{conversation_id}/title`、`POST /{conversation_id}/title`；前端 `updateConversationTitle`）。
- **删**：在侧边栏删除会话，确认后有 loading；取消不改变列表，确认成功后列表与快捷入口实时移除该会话。
- **收藏会话**：对当前会话点击收藏（后端 `POST /{conversation_id}/favorite`），在收藏列表可查到并在其他入口恢复。
- **权限**：无可用机构权限账号的历史会话不可绕过当前权限再次执行（结合 §4 权限回收场景）。

## 11. SQL 收藏（query-favorites）

- **增**：在 SQL 查询页点击「收藏」按钮（`SqlEditor.vue:2177` → `QueryFavoriteModal.vue`），输入收藏标题后保存，弹窗提示「收藏成功」；可视化查询同样可收藏（`QueryFavoriteModal` 的 `builder` 模式）。
- **查**：打开收藏列表（`QuickQueries.vue`），卡片网格展示已收藏 SQL / 可视化查询；空态有推荐问题兜底；会话空态、SQL 查询快捷入口均实时读取最新收藏。
- **改**：在收藏列表中点击「编辑收藏」，修改收藏标题并保存（后端 `PUT /query-favorites/{favorite_id}`），列表标题实时刷新。
- **删**：在收藏列表中点击「删除收藏」，二次确认弹窗（确认中显示「删除中…」）；取消不改变列表，确认成功后卡片实时移除。
- **用**：点击收藏项「重新执行」，使用已保存 SQL / 配置发起新查询，结果按统一成员结果展示；收藏内容为空时给出「当前可视化查询配置为空，无法收藏」提示。
- **SQL 历史（查询记录）**：在 SQL 查询页打开历史弹窗，能查看成功、失败、取消记录；点击「查看结果」（后端 `GET /query-history/{execution_id}/result`）可查看统一成员结果详情，页面不出现解析异常。

## 12. 技能管理（skills）

> 入口：数据智能体输入栏「技能管理」按钮 → `SkillManager.vue` 弹窗。后端 `skills.py` 提供创建、更新、删除、复制、发布、收藏和版本接口。

- **查（列表与可见性）**：
  - 列表支持按「全部 / 我的 / 收藏 / 系统」切换（后端 `GET /skills?scope=`）。
  - 私有技能（我的）：仅创建者可见、可编辑。
  - 公共技能（已发布 `published`）：所有人可见，原件不可被他人编辑；普通用户复制后生成自己的私有草稿副本可编辑。
  - 系统技能（`system`）：所有人可见，**所有人都不可以修改**（编辑时提示「系统技能文件仅支持查看」）。
- **增（创建）**：点击新建用户技能，填写名称 / 分类后保存为草稿（后端 `POST /skills`，`publish_status=draft`）；在当前用户「我的技能」中出现。
- **改（编辑与发布）**：
  - 编辑自己拥有的私有技能草稿的 `SKILL.md` 与 `references` 并保存（后端 `PUT /skills/{skill_id}`）；草稿可在管理界面查看，但未发布前不能被运行期 Agent 加载。
  - 点击「发布」发布当前草稿版本（后端 `POST /skills/{skill_id}/publish`，`published`）；是否被其他普通用户看到仍由 `visibility_type` 决定，发布不会自动把私有技能变成全局技能。
  - 版本管理：可查看版本列表、查看版本文件内容、编辑草稿版本文件、回滚到指定版本（后端 `GET/PUT/DELETE /skills/{id}/versions/...`、`POST .../rollback`）。
  - 系统技能仅可查看，任何编辑 / 发布 / 删除入口对系统技能禁用。
- **删（删除）**：删除自己创建的私有技能（后端 `DELETE /skills/{skill_id}`），确认后从「我的技能」移除；系统技能与他人的公共技能不可删除。
- **复制与收藏**：点击「复制技能」生成私有草稿副本（后端 `POST /skills/{skill_id}/copy`）；点击收藏星标收藏 / 取消收藏（后端 `POST/DELETE /skills/{skill_id}/favorite`），在「收藏」标签页可见。
- **导入（用户技能）**：在对话工作区检测到符合规范的技能目录时，可一键导入为「用户技能草稿」，导入后在技能管理中继续编辑。
- **Markdown 编辑**：选择 `SKILL.md` 或 references 中的 `.md` 文件后，可在「预览」和「源码」之间切换；只有源码模式允许修改并保存。

## 13. 页面稳定性与异常

- 打开、关闭右侧控制台，主内容区宽度恢复正常，长 JSON 可滚动不溢出。
- 展开、收起左侧栏并切换模式，页面不明显错位。
- 对保存、同步、执行、停止、删除等按钮快速重复点击，不产生重复任务、重复面板或重复删除。
- 查询执行中刷新浏览器，页面能恢复必要状态，不出现空白页。
- 页面触发权限不足、数据源不存在、网络失败时，错误提示用户可读；非 SQL 执行错误不展示后端堆栈。
