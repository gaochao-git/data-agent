# ChatData 浏览器点击测试待测项 v2

只记录需要通过浏览器页面点击验证的测试项，供测试同学拆 e2e / 手工回归 case。纯 API、单元测试、mock、数据库或日志验证不放这里。

## 前置数据

- 页面入口：`/chatdata`。
- 账号：管理员账号、普通账号、无可用机构权限账号。
- 数据：至少 1 个多执行对象数据源、1 个可用指标集、1 个已有会话、1 个已有看板、1 个已有技能。
- 权限回收场景：环境侧先回收部分机构权限，再刷新页面验证。

## 1. 页面入口与权限

- 管理员进入 `/chatdata`，切换数据智能体、可视化查询、SQL 查询、数据看板、指标集配置，页面无白屏、无无限 loading。
- 普通账号进入页面，后台管理入口不可见或不可操作。
- 无可用数据源或无机构权限账号进入页面，应展示空状态，不能误触发查询。
- 切换数据源、指标集、执行对象后，各模式状态不串台。

## 2. 数据源管理

- 管理员打开数据源管理，未修改配置时“保存配置”不可点击。
- 只修改基础配置并保存，不应触发表结构刷新。
- 点击“拉取表信息”只用于选择表；只有点击“同步元数据”才更新表结构缓存。
- 编辑数据源组后取消或关闭，再次打开应恢复服务端已保存状态。
- 删除数据源时，取消不改变列表；确认删除有 loading，成功后主页面不残留已删除数据源。

## 3. 指标集配置

- 管理员新建、编辑、删除公共指标集；保存后智能体和可视化查询可选择，删除后不可选择。
- 普通用户新建或编辑私有指标集；其他普通账号不可见或不可编辑。
- 自动预填后页面字段正确填充，字段表达式弹窗和表关联弹窗可编辑保存/取消，用户二次编辑不被异步结果覆盖。
- 历史学习入口有明确成功或失败提示。

## 4. 数据智能体

- 选择数据源、指标集、单个执行对象，输入明细查询，能生成 SQL、执行查询并展示结果表格。
- 选择多个执行对象做聚合查询，结果按成员展示，用户能看清 `member_name`。
- 页面不重复展示外层结果和成员结果，不同时展示互相矛盾的成功状态。
- 右侧控制台展示 JSON / 工具详情，不重复展示主结果表格。
- 工具卡片可展开详情，保留真实工具名，参数和结果可折叠且格式化可读。
- 工具结果中不重复展示无用工具名或重复参数，大结果不撑破页面。
- 保存到看板时，能正确带上 SQL、结果、执行对象信息。
- 回收部分机构权限后刷新页面，新查询不可选择已回收执行对象，历史会话不能绕过当前权限再次执行。

## 5. 上下文与系统提示词

- 默认配置下，上下文用量详情不展示 system prompt 原文。
- 开启系统提示词展示配置并重启后，新会话和历史会话页面可看到 system prompt 原文。
- 连续多轮问数触发压缩后，当前正在执行的一轮不丢失，后续问题仍能理解已确认的数据源、指标集和执行对象。
- 压缩后上下文用量展示应反映压缩后状态，不一直显示完整历史总量。

## 6. 智能分析

- 在输入区切换数据智能体和智能分析，不应清空已选数据源、指标集、执行对象。
- 智能分析可用时能正常查询数据、调用工具、生成图表或文件。
- 智能分析工具名称、工具详情、右侧控制台展示口径与智能问数一致。
- 生成文件可点击查看，文件树展开、收起、预览正常。
- 长任务执行中切换控制台、展开工具详情、切换会话，流式输出和状态不丢失。

## 7. SQL 查询

- 选择数据源和单个执行对象，输入 SELECT SQL 并执行，结果使用共享结果展示。
- SQL 错误可展示完整 SQL 执行错误，但页面不能出现解析异常。
- 选择多个执行对象执行同一 SQL，每个成员结果独立展示，耗时、行数、错误信息正确。
- SQL 编辑器运行、格式化等快捷键只在当前页面生效；AI 辅助生成 SQL 能流式回填编辑器，用户编辑不被后续流式片段覆盖。
- 发起耗时 SQL 后点击停止，状态变为已停止或部分停止失败，历史状态一致。

## 8. 可视化查询

- 选择维度、指标、过滤、排序、limit 后执行，生成 SQL 与页面配置一致。
- 修改条件后再次执行应刷新结果，不复用旧结果。
- 高级过滤树支持多层 AND / OR，展开、收起、删除、编辑不丢节点，删除后不残留旧过滤。
- 多执行对象可视化查询结果展示口径与 SQL 查询一致，并可保存到看板。
- 点击维度、指标区的设置按钮，分别打开管理弹窗；勾选删除、上下调整顺序、修改展示名称或聚合函数后保存，主配置区立即按保存结果更新；点击取消不修改主配置。
- 查询结果出现后，点击图表展示和结果分析 Tab、收起按钮及折叠后的竖向入口，面板可在对应 Tab 恢复，查询结果、图表类型、表格格式和分页设置不丢失。
- 图表展示中切换表格、柱状图、条形图、折线图、面积图、饼图、指标卡、地图、漏斗图和关系图，结果预览随选择更新；切换基本格式和分页器开关、页大小后，结果展示与分页行为一致。
- 结果分析依次点击排序、Top N、合计、百分比、对比、同环比并执行，结果仅在当前展示数据上变化且不修改 SQL；取消分析后恢复原始查询结果。
- 已有结果分析时继续执行另一种分析，使用当前展示结果作为输入；重新执行可视化查询或重置配置后，分析结果和分析条件清空，不能残留到新查询。
- 时间维度按周时，同环比入口不可执行并展示“暂不支持按周”提示；按年、季度、月、日时可执行，同环比结果字段、图表语义和原始结果切换正确。

## 9. 数据看板

- 从数据智能体、SQL 查询、可视化查询分别保存结果到看板，面板标题、图表类型、SQL、执行对象正确。
- 多执行对象结果保存后，看板面板能区分成员数据。
- 单面板刷新有 loading，执行成功后图表和表格更新。
- 批量刷新多个面板时，部分失败不影响其他成功面板展示。
- 回收部分机构权限后，已无权限执行对象不可新选择；绑定已回收执行对象的面板失败提示清晰。
- 编辑看板名称、面板名称、布局、图表类型并刷新，配置不丢失。

## 10. 历史、收藏、技能

- 新建智能问数会话、智能分析会话后切换历史，会话标题、消息、工具调用、结果、生成文件可恢复。
- SQL 历史能查看成功、失败、取消记录，结果详情仍按统一成员结果展示。
- 收藏 SQL、编辑收藏名、用收藏重新执行、删除收藏，列表和快捷入口实时刷新。
- 私有技能创建、编辑 `SKILL.md` 和 references 后，当前用户可见并可在智能体中选择使用。
- 公共技能发布后普通用户可见但不可编辑原件；复制后可编辑自己的副本。

## 11. 布局和异常

- 打开、关闭右侧控制台，主对话区宽度恢复正常，长 JSON 可滚动不溢出。
- 展开、收起左侧栏并切换模式，页面不明显错位。
- 对保存、同步、执行、停止、删除等按钮快速重复点击，不应产生重复任务、重复面板或重复删除。
- 查询执行中刷新浏览器，页面能恢复必要状态，不出现空白页。
- 页面触发权限不足、数据源不存在、网络失败时，错误提示用户可读；非 SQL 执行错误不展示后端堆栈。
