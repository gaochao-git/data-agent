# ChatData 发布版本必测功能 v1

每次发布前必须通过浏览器页面点击验证的稳定回归清单，目标是确认 ChatData 主要业务流程能跑通。版本专项、新增改动和临时风险项放 `v2.md` 或后续版本文件；纯 API、单元测试、mock、数据库或日志验证不放这里。

## 前置数据

- 页面入口：`/chatdata`。
- 账号：管理员账号、普通账号、无可用机构权限账号。
- 数据：至少 1 个可用数据源、1 个多执行对象数据源、1 个可用指标集、1 个已有会话、1 个已有看板。
- 环境：后端、前端、模型、查询数据源均使用本次待发布版本启动。

## 发布通过标准

- 下方主流程全部能通过页面点击完成，页面无白屏、无无限 loading、无前端未捕获异常。
- 查询结果展示、保存到看板、历史恢复、权限变化和异常提示使用统一口径。
- 非 SQL 执行错误不直接把后端堆栈展示给用户。

## 1. 入口与权限

- 管理员进入 `/chatdata`，可切换数据智能体、智能分析、可视化查询、SQL 查询、数据看板、指标集配置。
- 普通账号进入页面，管理类入口不可见或不可操作，个人可用数据正常展示。
- 无可用机构权限账号进入页面，展示空状态或无权限提示，不能误触发查询。
- 切换数据源、指标集、执行对象和功能模式后，页面状态不串台。

## 2. 数据源与指标集

- 管理员打开数据源管理，查看、编辑、保存数据源配置流程正常。
- 点击拉取表信息、选择表、同步元数据后，指标集配置可使用最新表结构。
- 新建公共指标集，选择表、字段、维度、指标并保存，智能问数和可视化查询能选择到。
- 普通账号新建私有指标集，当前用户可见，其他普通账号不可见或不可编辑。
- 编辑和删除指标集有确认或提示，保存后页面列表、下拉选择和历史引用表现一致。

## 3. 数据智能体

- 选择数据源、指标集、单个执行对象，输入明细查询，能生成 SQL、执行查询并展示结果。
- 选择多个执行对象查询，结果按成员展示，用户能看清成员名称和每个成员状态。
- 工具详情可展开查看，参数和结果格式化可读，大结果不撑破页面。
- 查询结果可保存到看板，保存后看板面板包含标题、SQL、执行对象和结果展示信息。
- 新建会话、切换历史会话后，消息、工具调用和查询结果可恢复。

## 4. 智能分析

- 从数据智能体切换到智能分析，已选数据源、指标集、执行对象不异常丢失。
- 输入分析问题后，能正常流式输出、调用工具、查询数据并生成分析结果。
- 生成图表或文件时，右侧文件树、预览、展开收起、下载或查看流程正常。
- 长任务执行中切换控制台、展开工具详情、切换会话，状态和流式结果不丢失。

## 5. SQL 查询

- 选择数据源和单个执行对象，输入合法 SELECT SQL，点击执行后异步任务成功完成并展示结果。
- 选择多个执行对象执行同一 SQL，每个成员结果独立展示，行数、耗时、错误信息正确。
- 输入高危 SQL 或非法 SQL 时，页面展示清晰错误，不执行危险操作。
- 发起耗时 SQL 后点击停止，任务状态进入已停止、失败或部分成功，历史记录状态一致。
- SQL 历史、收藏、重新执行、删除收藏流程可通过页面完成。

## 6. 可视化查询

- 选择维度、指标、过滤、排序和 limit 后点击执行，生成 SQL 与页面配置一致并展示结果。
- 修改查询条件后再次执行，应刷新为新结果，不复用旧结果。
- 多执行对象可视化查询结果与 SQL 查询展示口径一致。
- 可视化查询结果保存到看板后，面板图表类型、SQL、执行对象和结果正常。

## 7. 数据看板

- 打开已有看板，面板列表、布局、图表和表格能正常加载。
- 单面板刷新有 loading，完成后图表和表格更新。
- 批量刷新多个面板时，成功和失败面板互不影响，失败提示可读。
- 编辑看板名称、面板名称、布局、图表类型并保存，刷新浏览器后配置不丢失。
- 回收部分机构权限后，已无权限执行对象不可新选择；已有面板刷新失败时提示清晰。

## 8. 页面稳定性

- 打开、关闭右侧控制台，主内容区宽度恢复正常，长 JSON 可滚动不溢出。
- 展开、收起左侧栏并切换模式，页面不明显错位。
- 对保存、同步、执行、停止、删除等按钮快速重复点击，不产生重复任务或重复数据。
- 查询执行中刷新浏览器，页面能恢复必要状态，不出现空白页。
