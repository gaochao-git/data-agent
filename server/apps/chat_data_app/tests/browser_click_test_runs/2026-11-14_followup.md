### 2.3 根因与修复建议（本轮未改代码）

- 父：`SemanticConfigPanel.vue:2832` → `<SemanticHealthModal v-model:visible="showHealthModal" :result="healthResult" />`
- 子：`semantic/SemanticHealthModal.vue:14` → `const visible = defineModel<boolean>({ default: false })`（**默认模型名 `modelValue`**）

`v-model:visible` 传的是 `visible` prop + `update:visible` 事件；组件声明的是 `modelValue` prop + `update:modelValue`。两者永远对不上，`visible` 恒为 `false`。

**静态扫描确认是孤例笔误**：同目录 `ExpressionEditorDialog` / `OssieImportDialog` / `BusinessNotesDialog` / `TablePreviewDialog` / `MetricExpandDialog` / `SemanticEvaluationDrawer` / `SemanticHistoryLearningDialog` / `ColumnDictEditDialog` / `RelationshipEditorDialog` / `SemanticBatchToggleDialog` / `AddFieldDialog` 共 11 个组件，全部写作 `defineModel<boolean>('visible', ...)`；**只有 `SemanticHealthModal.vue` 漏了 `'visible'`**。全仓仅 `SemanticConfigPanel.vue:40` 一处 import、`:2832` 一处挂载，无其他调用方。

推荐修法（二选一，各一行）：

| 方案 | 改动 | 评价 |
| --- | --- | --- |
| **A（推荐）** | 父改 `v-model="showHealthModal"` | 符合 Vue 默认模型惯例，与「只此一处挂载」一致；影响面最小 |
| B | 子改 `defineModel<boolean>('visible', { default: false })` | 与同目录 11 个兄弟组件写法统一，但把命名模型固化到该组件 |

**修复后回归判据**：DS-12 应转 PASS —— 点「校验」出现两级弹窗（6 张缓存表 / 7 个语义模型）、点右上角自定义关闭按钮能关、**关掉后能再次打开**（`update:modelValue` 需正确同步回父 ref，否则第二次点不开）、控制台零错误。

### 2.4 影响面

仅管理员「语义模型管理 → 校验」入口的结果展示；接口、数据计算、其余 11 个同目录弹窗均不受影响。严重度建议 **P1（功能不可达，但一行可修）**。
