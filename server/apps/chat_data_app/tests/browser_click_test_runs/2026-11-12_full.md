### §4.1 页面入口与权限 (ENT-01~05)

- 角色：当前账号为管理员（SYS_ADMIN 等价）；USER_A 单用户流可借本账号模拟；多角色隔离用例标 BLOCKED。

#### ENT-01 页面模式切换

- 操作：打开页面，读取模式切换区；确认 `CHAT_DATA_USER_SEMANTIC_MODEL_ENABLED` 默认关闭时仅 4 个模式。
- 证据：
  - 页面 body 模式区文本为 `数据智能体 / 可视化查询 / SQL查询 / 数据看板`（4 个，无「语义模型配置」），与 ENT-01 预期「开关关闭时页签栏只有四个模式」一致。
- 结果：**PASS**（管理员态下 4 模式加载正常；语义模型配置 tab 因功能开关默认关闭而隐藏，符合预期）。
- 备注：开启开关后的 5 模式需 `CHAT_DATA_USER_SEMANTIC_MODEL_ENABLED=true` 后刷新验证，本环境未开启，列为 OBS，非缺陷。

#### ENT-02 管理入口可见性

- 操作：定位并点击 `button[title="后台管理"]`（注意：输入区附近还有一个文本为「管理」的按钮，实际是**技能管理**入口，不要混淆），读取后台管理弹窗内容。
- 证据（真实点击）：
  - 弹窗标题「后台管理」，左侧分组导航**三组齐全**：`数据资产`（数据源管理 / 语义模型管理 / 枚举值 / 数据血缘）、`智能体`（大模型管理 / 定时任务 / 插件管理 / 技能管理）、`系统`（运行配置 / 历史 SQL）。
  - 默认页「数据源管理」渲染 6 个数据源组，行内操作按钮 `编辑 / 分组 / 映射 / 删除`，`hive-localhost` 带「默认」标识，其余行显示「设默」。
  - 截图：`.workbuddy/screenshots/full_baseline_2026-11-12/ENT-02_admin_backend.png`
  - 接口权限：`GET /admin/datasources/{id}/semantic-configs` 与 `/admin/settings` 在本账号下均返回 `status=success / code=2000`。
- 结果：**PASS**（管理员可见并可进入后台管理，分组导航与数据源列表结构符合 SYS-02）。
- BLOCKED 子项：普通用户/无权限用户「不显示管理入口」及「直接调用 admin 地址返回无权限」——需 USER_A / NO_SCOPE_USER 独立账号，本环境仅管理员单账号。原因：§5.2 多角色账号缺失。

#### ENT-03 无权限与权限回收

#### ENT-04 页面状态恢复

- 操作：在四个模式分别配置筛选/文件/右侧面板状态，切换模式、关闭重开右侧控制台、刷新、切换历史会话，核对恢复。
