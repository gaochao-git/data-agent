### FAV-03 收藏编辑、复制和删除 — FAIL（DEF-01）

- 操作与结果：
  - 编辑：hover 卡片 → 「编辑收藏」弹窗 → 修改标题为「点击测试收藏_已改名」→ 保存成功，列表即时更新（PASS 部分）。
  - 删除：连续删除多条收藏时，**删除确认框标题显示为空**（「确认删除收藏「」吗？」），两次复现（正常单条删除时标题显示正确）。
- 缺陷 DEF-01：连续删除收藏时确认框内容为空。
  - 复现路径：删除第 1 条收藏的确认框未关闭时（或删除请求进行中）继续点击第 2 条的「删除收藏」→ 打开的确认框 `deletingTemplate` 为空对象，标题渲染为空字符串（`QuickQueries.vue:762` `deletingTemplate?.title || ''`）。
  - 风险：用户在空名确认框点击「删除」时行为不明确（`confirmDelete` 会以空 id 调用 `deleteQueryFavorite`），且用户无法确认删除对象。
  - 建议：`handleDelete` 中增加 `deletingTemplate` 有效性校验；或在确认框打开期间禁用卡片删除按钮；确认框打开时立即渲染标题。
- 清理：两条测试收藏均已删除（其中一条经由空名确认框打开前的方式正常删除）。
