# 数据分析报告结构参考

## 推荐章节

1. **管理摘要**：只写最重要的事实、变化和行动建议。
2. **分析范围与口径**：数据源、指标集、时间范围、过滤条件、单位、统计粒度和对比基准。
3. **经营概览**：核心指标当前值、目标值、同比/环比和异常标记。
4. **趋势分析**：按时间粒度展示变化，说明峰值、低点和拐点。
5. **结构与对比**：按区域、渠道、产品或客户群比较，必要时给出 TopN 和集中度。
6. **转化与异常**：只在阶段值有业务顺序且通常递减时使用漏斗；异常必须指向具体数据证据。
7. **结论与建议**：每条建议对应一个发现、证据和可执行动作。
8. **附录**：数据来源、生成时间、口径说明和必要的汇总表。

## 结论写法

使用“事实 -> 判断 -> 建议”的顺序：

```text
事实：某指标在指定期间从 A 变化到 B，变化率为 C。
判断：结合指定分组和对比口径，主要变化来自 D。
建议：优先核查或采取 E，并用 F 指标跟踪效果。
```

不要使用“显著”“大幅”“主要原因”等没有数值或分组证据支撑的表达。无法从当前查询证明因果关系时，写“与……同时出现”或“需要进一步核查”，不要写成因果结论。

## 图表选择

| 分析问题 | 推荐图表 | 注意事项 |
|---|---|---|
| 时间变化 | 折线图 | X 轴按时间顺序，粒度一致 |
| 分类比较 | 柱状图 | 类别过多时限制 TopN 并说明规则 |
| 构成占比 | 饼图 | 类别不宜过多，数值应为非负且总量可解释 |
| 阶段转化 | 漏斗图 | 仅用于有顺序的转化/流失阶段 |
| 连续累计趋势 | 面积图 | 不要把无序分类数据画成面积图 |
| 同比/环比 | 双系列折线或柱状图 | 按同期位置对齐，不把不同年份直接串成一条时间轴 |
