# 国央企内部管理汇报格式

本规范适用于经营分析、专题汇报、工作总结、情况报告、调研报告等内部管理材料。它不是党政机关正式公文格式；请示、通知、决定、函等正式公文应优先使用用户单位模板，并按需参考 `/mnt/skills/officecli/references/gb-t-9704-2012.md`。

## 默认模板

用户未提供模板或格式时，先复制只读模板：

`/mnt/skills/officecli/assets/internal-management-report-template.docx`

到 `/mnt/user-data/workspace/`，再用 OfficeCLI 编辑。不要直接修改 `/mnt/skills/` 中的模板，也不要以 `officecli create` 生成的极简文档作为内部汇报的最终起点。

模板中的实际样式定义是格式事实源；本文件用于选择样式和验收，不要再对每个段落自由指定字体、字号、颜色或行距。用户模板和用户明确要求优先于本规范。

## 样式映射

- `ReportTitle`（报告标题）：主标题；模板为方正小标宋简体 22pt、居中。
- `ReportSubtitle`（报告副标题）：副标题或主题语；模板为楷体_GB2312 16pt、居中。
- `ReportMeta`（报告信息）：汇报单位、日期等封面信息；模板为仿宋_GB2312 14pt、居中。
- `Heading1`（一级标题）：模板自动生成“一、”；黑体 16pt。
- `Heading2`（二级标题）：模板自动生成“（一）”；楷体_GB2312 16pt。
- `Heading3`（三级标题）：模板自动生成“1.”；仿宋_GB2312 16pt 加粗。
- `Normal`（正文）：仿宋_GB2312 16pt、两端对齐、首行缩进 2 字符、固定 28pt 行距。
- `KeyConclusion`（关键结论）：只用于最重要的 1-3 条结论，不要把大段正文放入强调块。
- `TableCaption`（表题）：表格上方标题。
- `FigureCaption`（图题）：图表或图片下方标题。
- `Note`（说明文字）：口径、数据来源、注释等次要信息。
- `TableHeader` / `TableText`：表头和表格正文；表格优先使用模板内的 `InternalReportTable` 表格样式。

不要在标题正文里手写“一、”“（一）”“1.”，避免与模板自动编号重复。新增段落时只写标题文本并设置对应 `Heading1`、`Heading2` 或 `Heading3` 样式。

## 内容组织

- 封面与正文分节：封面不显示页码，正文另起一页并从 `- 1 -` 开始编号。
- 结论先行：管理层摘要应优先写事实、判断、影响和行动，不先堆背景。
- 一段一意：避免超长段落；重要数据保留统计范围、单位和时间口径。
- 层级克制：通常不超过三级标题；层级过深时优先重组内容。
- 表格可读：表头简洁、单位明确，正文一般使用 10.5-12pt，不套用 16pt 正文字号。
- 图表克制：白底，以深蓝为主色、红色作重点强调；避免渐变、立体效果和无业务含义的装饰。
- 密级、单位标识和页眉内容只有用户明确提供或单位模板已有时才写，不自行推断。

## 字体回退

模板首选方正小标宋简体、仿宋_GB2312、楷体_GB2312、黑体和宋体。目标电脑缺少字体时，Word 可能替换字体；若部署环境无法保证字体，应使用单位统一字体模板，或由用户提供已安装字体清单后调整模板。

## 交付检查

1. `officecli validate` 必须通过。
2. 用 `view annotated` 确认标题、正文、说明和表格使用正确样式，标题编号没有重复。
3. 用 `view issues` 检查空段、占位符、裁切、表格越界和图片替代文本；动态 `PAGE` 域在 Word 首次打开前可能没有缓存结果，这不是固定页码，可保留并明确由 Word 打开时更新。
4. 用 `view text` 确认不存在 `{{...}}`、`TBD` 等未替换占位符。
5. 对超过一页、包含表格/图表或需要正式汇报的文档，必须进行 HTML、截图或目标 Office 查看器的视觉检查；结构校验通过不代表排版正确。
