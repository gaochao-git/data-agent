# 备付金非现场监管业务背景

## 覆盖范围

本领域用于理解备付金非现场监管相关问数问题，包括机构基础信息、机构上报数据、数仓加工汇总和预计算结果。

本文件只维护业务理解方法，不维护完整物理表结构、SQL 表达式或 JOIN 细节。

## 业务对象

常见对象包括：

- 支付机构、法人机构、分支机构。
- 备付金账户、合作银行、账户余额。
- 交易、退款、清算、结算、提现、充值等业务流水。
- 机构上报记录、监管报表、统计期或账期。

实际对象名称必须以当前语义配置中维护的指标、维度和字段说明为准。

## 常见时间概念

- 业务日期：业务实际发生日期。
- 上报日期：机构报送数据日期。
- 统计日期或账期：监管统计口径对应日期。
- 入库日期：数据进入系统或数仓的日期。

如果当前语义配置没有明确某个时间字段代表哪种口径，不能自行混用；涉及趋势、排行、对比时应追问或说明缺少时间口径。

## 口径来源

用户问题可能指向不同来源：

- 原始上报：适合明细、逐笔、上报记录和细粒度筛选。
- 加工汇总：适合按机构、时间、类型等维度做汇总。
- 预计算结果：适合固定监管口径、固定统计周期和高频报表问题。
- 基础信息：适合机构属性、账户属性、机构分类等筛选和分组。

同一业务词在不同来源可能代表不同粒度或口径，不能只按名称选择。

## 与语义配置的关系

业务说明帮助模型理解用户说法，语义配置决定是否可以执行。

- 技能说某个业务对象常见，但语义配置没有对应指标或维度时，不能查询。
- 技能说明某类口径可能存在，但当前指标集维护了不同口径时，以当前指标集为准。
- 技能可帮助选择明细、汇总或预聚合方向，但不能让模型绕过 DSL 直接写 SQL。
