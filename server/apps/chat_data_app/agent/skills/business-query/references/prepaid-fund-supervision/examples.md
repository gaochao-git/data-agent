# 备付金非现场监管典型问法

## 明细查询

用户：查询某机构某日期的上报明细。

处理：

- 判断为明细查询。
- `metrics=[]`。
- 需要展示的字段放入 `dimensions`。
- 如果当前指标集没有明细字段或对应时间口径，说明当前配置不支持。

## 月度趋势

用户：按月查看某指标趋势。

处理：

- 判断为趋势查询。
- 需要时间范围和月粒度时间维度。
- 优先选择月粒度或可按月上卷的口径。
- 如果指标是余额、比率或预计算值，不能默认跨月 SUM。

## 机构排行

用户：查看前 10 个机构的某指标排名。

处理：

- 判断为排行查询。
- 需要明确排序指标和时间范围。
- `order_by` 只能使用当前 DSL 输出字段。
- 如果“最好、最高、最多”可能对应多个指标，先追问。

## 同名指标

用户：查询某指标。

现象：当前可用配置中存在同名的明细口径和预聚合口径。

处理：

- 用户说“明细、列表、逐笔、上报记录”时，选择明细口径。
- 用户说“月度、趋势、报表、汇总、监管统计”时，选择对应汇总或预聚合口径。
- 用户没说明粒度且两种口径结果可能不同，先追问。
