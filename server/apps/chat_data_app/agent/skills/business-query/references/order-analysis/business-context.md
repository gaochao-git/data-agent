# 订单销售分析业务背景

## 覆盖范围

本领域用于理解订单、商品、类目、销售额、销量、用户和成交分析相关问数问题。

本文件只维护业务理解方法，不维护完整物理表结构、SQL 表达式或 JOIN 细节。实际可查询内容必须以当前语义配置中的指标、维度、枚举、日期格式、单位和关系为准。

## 业务对象

常见对象包括：

- 订单：订单编号、订单状态、下单时间、支付时间、成交时间、取消或退款信息。
- 订单明细：订单商品行、商品数量、明细销售额、成交单价。
- 商品：商品 ID、商品名称、商品分类、父类目、类目层级、是否启用。
- 用户：用户数量、购买用户、成交用户、新老用户等。
- 类目：商品分类、父类别、层级、类别描述。

用户说“订单”“销量”“销售额”“成交”“商品”“类目”时，需要结合当前指标集判断是订单粒度、订单明细粒度、商品粒度还是类目汇总口径。

## 常见指标理解

- 销量：通常指销售商品数量，可能来自订单明细数量聚合，也可能是预计算销量指标。
- 销售额：通常指成交金额或明细销售额汇总，必须看当前指标说明确认是否含退款、优惠、取消订单。
- 订单数量：通常指订单数，不等同于订单明细行数。
- 用户数量：通常指用户去重数量，不等同于订单数量。
- 平均成交单价：可能是销售额除以销量，也可能是预计算均值；不能默认二次平均。

如果当前语义配置没有明确口径，不要自行假设“销售额是否含退款”“订单状态如何过滤”“用户数量是否去重”等规则。

## 常见时间概念

- 下单时间：用户创建订单的时间。
- 支付时间：订单完成支付的时间。
- 成交时间：订单进入成交口径的时间。
- 统计日期：数仓或报表已经加工好的统计日期。

查询“今日销量”“本月销售额”“上个月同一天”等问题时，必须确认当前时间维度代表哪种时间口径。若语义配置只维护了一个时间维度，则按该维度执行；如果多个时间维度都可能匹配，应追问。

## 与语义配置的关系

- 技能帮助模型理解订单领域问法，语义配置决定是否能查询。
- 技能中的业务解释不能覆盖当前指标集中的真实指标说明和字段口径。
- 当前指标集缺少类目、商品、用户、时间或订单状态维度时，不能自行补 SQL 或猜测关联。
