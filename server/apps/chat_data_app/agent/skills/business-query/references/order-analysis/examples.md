# 订单销售分析典型问法

## 今日销量

用户：查询今天销量。

处理：

- 判断为单指标聚合查询。
- 使用当前指标集中的“销量”指标。
- 使用当前指标集明确维护的时间维度筛选今天。
- 如果没有时间维度或日期格式不明确，应说明缺少时间口径。

## 今日和上个月同一天销量差额

用户：查询今日销量和上个月同一天销量，并计算差额。

处理：

- 拆成两个基础查询，分别查询今天和上个月同一天的销量。
- 两次查询都必须使用同一个销量指标和同一个时间维度口径。
- 查询结果为 null 或空时，不要当成 0，除非业务规则明确要求。
- 两个结果都有数值时，再用 `calculator_tool` 计算差额。

## 商品类目销量排行

用户：按商品分类查看销量前 10。

处理：

- 判断为聚合排行。
- `metrics` 使用“销量”。
- `dimensions` 使用当前指标集中真实存在的商品分类或类目维度。
- `order_by` 使用销量降序，`limit=10`。
- 如果存在多个类目层级，应确认使用商品分类、父类目还是层级。

## 订单明细

用户：查看某个订单的明细。

处理：

- 判断为明细查询。
- `metrics=[]`。
- 展示字段放入 `dimensions`。
- 使用订单编号等维度过滤。
- 如果当前指标集没有订单编号或明细字段，说明当前配置不支持。
