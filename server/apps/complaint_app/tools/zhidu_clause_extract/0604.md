# 0604 制度冲突分析新批次执行说明

本文档用于 0604 新批次制度分析。由于本批次同时变化了 `outline.xlsx` 和 `pdfs`，需要从头完整产出一套新结果，避免和 0430 旧结果混用。

## 0. 进入环境

作用：进入服务端目录，并加载 UAT 环境变量。

```bash
cd /opt/aigc/fxcjg/server

set -a
source .env
set +a
```

## 1. 准备输入目录

作用：确认新批次输入文件已经放好。

需要准备：

- `/data/aigc/zhidu_0604/outline.xlsx`
- `/data/aigc/zhidu_0604/pdfs`

## 2. 一键执行完整链路

作用：按顺序执行新版 outline 解析、PDF 抽取、制度映射、有效规则、摘要、组内/组间冲突、严格复核、最终 Word 报告导出。

```bash
bash apps/complaint_app/tools/zhidu_clause_extract/run_fawubu_full_batch.sh \
  /data/aigc/zhidu_0604 \
  /data/aigc/zhidu_0604/outline.xlsx \
  /data/aigc/zhidu_0604/pdfs
```

## 3. 脚本内部执行顺序

### 3.1 生成 outline 元数据

作用：读取新版 `outline.xlsx`，生成制度目录结构和版块信息。

产出：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/merged_outline.json`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/inter_group_pairs.json`

### 3.2 PDF 抽取与条款切分

作用：读取新版 `pdfs` 目录，抽取制度正文、切分条款。

产出：

- `/data/aigc/zhidu_0604/output/01_extract/documents.jsonl`
- `/data/aigc/zhidu_0604/output/01_extract/clauses.jsonl`
- `/data/aigc/zhidu_0604/output/01_extract/raw_texts/*.txt`

### 3.3 documents 映射新版 outline

作用：把每份制度匹配到新版 outline，带出新版版块、主责部门、制度级别等字段。

产出：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/document_outline_mapping.jsonl`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/document_outline_mapping.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/document_outline_mapping_summary.json`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/documents_mapped.jsonl`

### 3.4 生成有效规则

作用：基于条款结果筛选有效制度规则，剔除解释权、生效日期、废止原制度等文件自身管理条款。

产出：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_effective_rules_fawubu/effective_rules.jsonl`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_effective_rules_fawubu/effective_rules.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_effective_rules_fawubu/effective_rules_summary.json`

### 3.5 补充制度摘要

作用：给每份制度补充摘要信息，辅助后续判断条款是否处于同一业务语境。

产出：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_effective_rules_fawubu/effective_rules_with_summary.jsonl`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_effective_rules_fawubu/effective_rules_with_summary_summary.json`

### 3.6 组内冲突分析

作用：同一版块内制度两两比较；其中“一级制度 vs 二级制度”的制度对会被跳过，因为一级制度是上位原则，二级制度是实施细则。

产出：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zunei_fawubu/doc_pair_review.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zunei_fawubu/high_conflict_clauses.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zunei_fawubu/high_conflict_clause_candidates.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zunei_fawubu/summary.json`

### 3.7 组间冲突分析

作用：只按内置指定版块对做跨版块比较，不做全部版块两两比较。

产出：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zujian_fawubu/doc_pair_review.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zujian_fawubu/high_conflict_clauses.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zujian_fawubu/high_conflict_clause_candidates.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zujian_fawubu/summary.json`

### 3.8 严格复核

作用：对条款级候选再做严格复核，保留模型判断明确成立的冲突。

产出：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zunei_fawubu/strict_review/high_conflict_candidates_strict.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zunei_fawubu/strict_review/strict_review_summary.json`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zujian_fawubu/strict_review_inter/high_conflict_candidates_strict.xlsx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zujian_fawubu/strict_review_inter/strict_review_summary.json`

### 3.9 最终 Word 报告

作用：合并组内和组间结果，输出最终给用户查看的两个 Word。

非严格版：

- 合并组内和组间。
- 候选按 `high -> medium -> low` 排序。
- 每条候选展示两份制度的主责部门和制度级别。

严格版本：

- 合并组内和组间。
- 只保留 `high` 候选。
- 每条候选展示两份制度的主责部门和制度级别。

最终产出：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_conflict_word_reports/冲突报告-非严格版.docx`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_conflict_word_reports/冲突报告-严格版本.docx`

## 4. 执行后重点检查

### 4.1 检查 outline 映射

作用：确认新版制度是否都匹配到 outline。

查看：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/document_outline_mapping_summary.json`

重点关注：

- `matched`
- `ambiguous`
- `unmatched`

### 4.2 检查有效规则

作用：确认制度是否都成功进入有效规则提取。

查看：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_effective_rules_fawubu/effective_rules_summary.json`

重点关注：

- `status_counts`
- `total_valid_rules`
- `total_invalid_rules`

### 4.3 检查组内/组间冲突

作用：确认组内、组间是否都正常跑完。

查看：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zunei_fawubu/summary.json`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zujian_fawubu/summary.json`

重点关注：

- `pair_count`
- `possible_conflict_count`
- `error_count`
- `high_clause_locate_candidate_count`

### 4.4 检查严格复核

作用：确认严格复核保留了多少候选。

查看：

- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zunei_fawubu/strict_review/strict_review_summary.json`
- `/data/aigc/zhidu_0604/output/02_outline_mapping/zhidu_doc_pair_review_zujian_fawubu/strict_review_inter/strict_review_summary.json`

重点关注：

- `original_candidate_count`
- `strict_candidate_count`
- `rejected_candidate_count`
- `strict_confidence_counts`
