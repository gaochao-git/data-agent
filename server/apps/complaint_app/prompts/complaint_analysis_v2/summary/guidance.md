
## 处理规则

仔细阅读举报信全文，提取以下信息（严格基于原文，不添加原文中没有的内容）。

根据 `{{reporter_name}}` 和 `{{reported_institution}}` 是否为空，选择对应模式：

### 锚定模式（两者均不为空时启用）

以 `{{reporter_name}}` 和 `{{reported_institution}}` 为锚点，对信息进行定向提取和筛选：

- **举报人锚定**：以 `{{reporter_name}}` 为身份锚点，在信中定位该人的所有陈述、主张和诉求。信中涉及其他人的内容不纳入举报事项和诉求，仅在备注中简要提及
- **被举报机构锚定**：以 `{{reported_institution}}` 为被举报对象锚点，仅提取与该机构直接相关的举报事项和行为。信中涉及其他机构的内容仅在备注中简要提及
- **事项筛选**：举报事项清单仅列出与 `{{reported_institution}}` 直接相关的指控
- **诉求筛选**：仅列出 `{{reporter_name}}` 针对 `{{reported_institution}}` 提出的诉求

### 常规模式（变量为空时）

从信中提取全部信息，不做筛选。

## 输出格式

请严格按照以下 Markdown 格式输出：

```markdown
## 事件概要
用3-5句话概括举报信描述的核心事件经过（人物、时间、经过、结果）。

## 当事方信息
- 举报人：{{reporter_name}} 不为空时直接使用；为空时从原文提取；如为匿名举报，标注"匿名举报"
- 被举报机构：{{reported_institution}} 不为空时必须逐字直接使用，不得改写、补充、扩展或引用原文中的其他机构；为空时从原文提取

## 举报事项清单
（如果举报人进行了分类，按举报人的原始分类标题逐类输出，保持客观陈述，不添加主观判断）
- 事项{n}：{一句话概括}
  - 原文描述：「{摘录原文关键描述}」
  - 举报人提及的法条或相关规定：{有则列出，无则标注"未明确提及"}

## 举报人诉求
逐条列出。

## 关键时间线
按时间顺序列出关键节点（如有明确时间信息）。

## 附件/证据
- （如有提及的附件、证据材料，列出清单）

## 备注
- （需要特别说明的事项，如信息缺失、矛盾点等）
```

## 注意事项
- 对举报信中**无法确认的信息**，使用"据举报人称"等措辞，保持客观
- 如举报信内容**混乱或缺乏条理**，在摘要中注明并尽量还原逻辑
- **不要编造**原文中没有的信息
- 如发现举报信中存在**逻辑矛盾**，在备注中指出
- **法律法规可能集中出现在其他章节中，而非逐条嵌入举报事项内部，务必全文检索并与举报事项一一对应**
- 输出使用**中文**
- 摘要应**准确、简洁、结构清晰**，便于后续审查
- **锚定模式下**，信中涉及但与锚定主体无关的其他当事人或机构信息，在备注中简要提及（如"信中还涉及XX银行的相关描述，不在本摘要分析范围内"），确保不遗漏但不干扰主分析
