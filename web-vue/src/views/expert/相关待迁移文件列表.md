根据我对代码库的深入分析，以下是法律助手（/expert 路径）迁移到 Vue 所需涉及的所有前端文件清单：

  核心入口与路由文件

  1. web/src/App.tsx - 主应用路由配置，定义了 /expert/:conversationId? 路由指向 GeneralAssistant 组件

  主要页面/布局组件（GeneralAssistant 目录）

  2. web/src/pages/GeneralAssistant/index.tsx - 入口组件，处理登录重定向并渲染 Layout
  3. web/src/pages/GeneralAssistant/Layout.tsx - 核心布局组件，包含：
    - 历史对话侧边栏 (HistorySidebar)
    - 顶部导航栏 (TopNavBar)
    - 对话区域 (Conversation)
    - 智能体容器 (AgentContainer)
  4. web/src/pages/GeneralAssistant/types.ts - 类型定义文件（Agent, ChatMessage, ConversationHistoryItem 等）
  5. web/src/pages/GeneralAssistant/constants.ts - 常量定义

  智能体注册与配置

  6. web/src/pages/GeneralAssistant/agentRegistry.ts - 智能体注册表，定义了 expert_agent 配置
  7. web/src/pages/GeneralAssistant/agentConfig/expertAgent.ts - 法律检索智能体的具体配置（ID: expert_agent，名称: 法律检索）
  8. web/src/pages/GeneralAssistant/agentConfig/components.ts - 动态加载嵌入组件的配置

  子组件（components 目录，部分公共组件已完成Vue中迁移，详见web-vue\src\views\general_assistant\Layout.vue）

  9. web/src/pages/GeneralAssistant/components/AgentContainer.tsx - 智能体容器，负责动态加载嵌入组件
  10. web/src/pages/GeneralAssistant/components/AgentGrid.tsx - 智能体网格卡片展示
  11. web/src/pages/GeneralAssistant/components/Conversation.tsx - 对话消息展示和输入组件
  12. web/src/pages/GeneralAssistant/components/HistorySidebar.tsx - 历史对话侧边栏
  13. web/src/pages/GeneralAssistant/components/TopNavBar.tsx - 顶部导航栏

  统一嵌入布局组件（unified 子目录）

  14. web/src/pages/GeneralAssistant/UnifiedEmbeddedLayout.tsx - 专家/投诉举报的统一嵌入布局
  15. web/src/pages/GeneralAssistant/components/UnifiedEmbeddedContent.tsx - 统一嵌入内容组件，包含对话消息和工作台
  16. web/src/pages/GeneralAssistant/components/unified/Conversation.tsx - 统一对话组件
  17. web/src/pages/GeneralAssistant/components/unified/Workbench.tsx - 工作台容器
  18. web/src/pages/GeneralAssistant/components/unified/workbench/ExpertWorkbench.tsx - 法律检索工作台（右侧法规依据面板）
  19. web/src/pages/GeneralAssistant/components/unified/conversation/Composer.tsx - 输入框组件
  20. web/src/pages/GeneralAssistant/components/unified/conversation/ConversationMessages.tsx - 消息列表
  21. web/src/pages/GeneralAssistant/components/unified/conversation/ThinkingBlock.tsx - 思考块展示

  Hooks 和工具函数

  22. web/src/pages/GeneralAssistant/hooks/useGeneralAssistant.ts - 核心 Hook，管理对话状态、历史记录、API 调用
  23. web/src/pages/GeneralAssistant/hooks/index.ts - Hooks 导出
  24. web/src/pages/GeneralAssistant/utils/parseChatSse.ts - SSE 消息解析

  老版 AISpecialistHome 可能被复用组件，其他文件不建议参考

  28. web/src/pages/AISpecialistHome/EmbeddedLayout.tsx - 嵌入布局（被 components.ts 引用）
  33. web/src/pages/AISpecialistHome/RightPanels/PolicyPreviewPanel.tsx - 法规预览面板（被 ExpertWorkbench 使用）
  34. web/src/pages/AISpecialistHome/RightPanels/TracePanel.tsx - 调试面板
  37. web/src/pages/AISpecialistHome/types.ts - 类型定义（ParsedCitation 等）

  总结

  迁移到 Vue 需要重点关注以下核心文件：

  1. 配置层: agentConfig/expertAgent.ts - 定义了法律检索智能体的元数据
  2. 布局层: UnifiedEmbeddedLayout.tsx 和 Layout.tsx - 整体页面结构
  3. 组件层: UnifiedEmbeddedContent.tsx, ExpertWorkbench.tsx, PolicyPreviewPanel.tsx - 核心 UI
  4. 状态层: useGeneralAssistant.ts - 数据流和 API 交互
