
# 启动 web-vue 查看 inspection 迁移效果

## 前置条件
1. 确保后端服务已启动（默认端口 5001）
2. 如果没有后端，启动脚本在 server/main.py

## 启动步骤

### 1. 进入 web-vue 目录
```bash

```

### 2. 安装依赖（如果还没安装）
```bash
pnpm install
```

### 3. 启动开发服务器
```bash
pnpm run dev
```

### 4. 访问页面
启动后会显示访问地址，通常是：
- http://localhost:8089 或 http://127.0.0.1:8089

### 5. 查看执法检查模块
在浏览器中访问：
- http://localhost:8089/inspection

或者从侧边栏菜单点击"执法检查"进入。

## 常见问题

### 端口冲突
如果 8089 端口被占用，可以修改 vite.config.ts 中的 port 配置。

### API 代理问题
确保后端服务运行在 http://127.0.0.1:5001，
否则需要修改 vite.config.ts 中的 agentUrl 配置。

### 页面空白或报错
1. 检查浏览器控制台（F12）查看错误信息
2. 确保所有依赖已正确安装
3. 尝试重启开发服务器
